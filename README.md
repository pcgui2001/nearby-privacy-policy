# NearBy Privacy Policy

Last updated: March 29, 2026

NearBy is a location-based reminder app. This policy explains how we handle your data.

## Data We Collect
- Location data (to detect when you're near a saved location)
- Reminders you create (stored locally on your device only)

## How We Use Your Data
- Location is used only to trigger reminders when you're nearby
- Your reminders are stored on your device and never sent to any server

## Data Sharing
We do not sell, share, or transmit your personal data to any third parties.

## Third Party Services
- Google Maps API (for location search and maps)
- Google Places API (for location autocomplete)
